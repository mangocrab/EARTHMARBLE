# 지구마블 · Earth Marble

**방에서 AI를 초대해 싱글플레이하는 GitHub Pages 모드**를 지원합니다. 서버 주소 없이도 공개 PeerJS 신호 서버와 WebRTC 직접 연결을 통해 실제 사용자 매칭·방 참가를 할 수 있습니다. 모바일에서는 기본으로 전체 40칸을 한 화면에 표시합니다. [플레이·정적 배포 안내](docs/PAGES.md)를 참고하세요.

```sh
npm run dev:solo      # 서버 없는 AI 단독 모드 개발
npm run build:pages   # GitHub Pages용 dist-pages 생성
```

지구과학을 주제로 한 독립 실행형 실시간 웹 보드게임입니다. 닉네임을 등록하고 친구와 비밀번호 방을 만들거나, AI 대원을 초대하거나, 10초 단위 자동 매칭으로 2~4인이 플레이할 수 있습니다. 연구비는 게임 전용 정수 자원이며 실제 금전·외부 포인트와 연결되지 않습니다.

## 실행

Node.js **24 이상**, npm이 필요합니다. SQLite는 Node 내장 모듈을 사용하므로 별도 DB 서비스나 API 키가 필요하지 않습니다.

```sh
cd /workspace/EARTHMARBLE
npm ci --cache /workspace/.npm-cache
npm run dev
```

기본 포트는 `3000`입니다. 개발 서버 한 개가 API, Socket.IO, Vite 화면을 함께 제공합니다. 브라우저별로 독립된 세션이므로 두 명을 테스트하려면 다른 브라우저 또는 시크릿 창을 사용합니다. 혼자 플레이할 때는 **방 만들기 → AI 초대 → 준비 완료 → 탐사 시작**을 선택합니다.

배포용 실행:

```sh
npm run build
npm start
```

외부 HTTPS 리버스 프록시에서는 WebSocket 업그레이드를 지원하고 `COOKIE_SECURE=true`를 설정하세요. 단일 Node 프로세스 운영을 전제로 합니다. 여러 서버 인스턴스 운영에는 공유 세션·매칭 저장소와 방별 단일 실행자, Socket.IO 어댑터 구성이 추가로 필요합니다. 이 저장소만으로 외부 서비스에 배포되거나 환경이 게시되지는 않습니다.

| 환경 변수                 | 기본값                    | 용도                                |
| ------------------------- | ------------------------- | ----------------------------------- |
| `PORT`                    | `3000`                    | HTTP 및 WebSocket 포트              |
| `DATA_DIR`                | `.data`                   | SQLite DB 보관 경로; 쓰기 권한 필요 |
| `COOKIE_SECURE`           | `false`                   | HTTPS 운영 시 `true`                |
| `IDENTITY_ADAPTER_MODULE` | 미설정                    | 외부 사이트 인증 어댑터 모듈 경로   |
| `CHROMIUM_PATH`           | 설치된 Chromium 자동 탐색 | 브라우저 테스트용 실행 파일         |

`.data/earth.sqlite`에 세션 토큰의 SHA-256 해시, 세션 만료, 방 설정, 요청 중복 처리 기록과 서버 전용 게임 상태를 저장합니다. 원본 토큰은 HttpOnly·SameSite=Strict 쿠키에만 전달합니다. 방 비밀번호는 임의 salt를 포함한 scrypt 해시로 저장합니다. DB 백업은 SQLite 백업 방식 또는 서버 중지 후 WAL 파일까지 함께 보관하는 방식을 사용하세요. 게임 스냅샷에는 덱 순서와 비공개 카드가 있으므로 DB를 공개하지 마세요.

## 검증

```sh
npm test              # 규칙·AI 시뮬레이션·실제 Socket.IO 서버 통합
npm run build         # TypeScript 검사 + 프로덕션 클라이언트 빌드
npm run test:e2e      # 위 빌드 후 PC 및 모바일 Chromium 테스트
```

브라우저 테스트는 `/usr/bin/chromium`이 있으면 사용합니다. 없으면 `npx playwright install --with-deps chromium`으로 Playwright Chromium과 시스템 의존성을 설치하세요. 테스트 서버는 별도 포트 `3196`/`3197`/`3198`/`3199`/`3202`을 사용합니다. 통합·수명주기·증서 동기화 테스트 DB는 임시 디렉터리, 기본 E2E DB는 `.data/e2e` 및 `.data/e2e-external`에 저장되어 실제 게임 DB를 건드리지 않습니다. 브라우저 테스트 결과·화면 캡처·실패 추적은 `test-results/`에 생성됩니다.

검증 범위와 설계상 결정은 [검증 기록](docs/VALIDATION.md)을 참고하세요. 원본 명세 대조에서 찾은 누락의 수정 결과와 남은 운영 검증 범위는 [명세 누락 수정 및 검증](docs/SPEC_RESOLUTION.md)에 정리했습니다. 모든 명세 항목을 수동으로 검증했다는 뜻은 아닙니다.

## 게임 진행

- 2인은 150만, 3~4인은 300만 연구비로 시작합니다. AI도 인원에 포함됩니다.
- 출발지는 오른쪽 아래입니다. 시계 방향 정상 완주마다 연구비 20만과 완주 1회를 받습니다.
- 구매는 도착한 빈 소유지에서만 가능합니다. 건설은 자신의 소유지 재도착 시 완주 횟수에 따라 관측소 → 연구소 → 종합연구센터 순서로 건설합니다. 한 번 도착했을 때 완주 해금·자금 조건을 충족하는 시설을 여러 개 이어 지을 수 있습니다.
- 통행료는 토지와 **존재하는 모든 시설**의 요금을 합산합니다. 특수 소유지는 고정 요금만 적용합니다.
- 주사위는 서버의 암호학적 난수로 정합니다. 클라이언트는 결과를 연출하며 WebGL 실패 시 2D 눈으로 대체합니다.
- 행동 제한은 60초, 주사위 연출은 2.4초이며, 말 이동은 칸마다 진행하되 6칸 이상은 총 1.44초로 가속합니다. 자동 연산과 연출 동안 행동 타이머는 진행하지 않습니다. 더블 추가 굴림은 새 60초를 받습니다.
- 같은 차례의 주사위·구매·건설·카드 사용·자산 매각은 남은 시간을 공유합니다. 탈출권 사용이나 매각 후 정산으로 60초가 다시 주어지지 않으며, 연출·자동 정산에 실제로 걸린 시간만 제외합니다. 시간이 다 되어 자동으로 주사위를 굴린 경우 이후 구매·건설도 기본 포기 규칙을 따릅니다.
- 카드 30장은 공용 덱에서 순서대로 뽑습니다. 즉시 카드는 버림 더미, 보관 카드는 소유자에게만 보입니다. 사용하거나 파산한 보관 카드는 남은 덱의 임의 위치로 반환됩니다.
- 비용이 부족하면 내 소유지 → 카드 뒷면에서 시설·토지를 절반 가격에 매각할 수 있습니다. 건물은 비싼 순서로 팔아야 하며 건물을 모두 팔아야 토지를 팔 수 있습니다. 정산 중 부족분 자동 매각은 건물을 싼 순서로 먼저 팔고, 이후 토지를 싼 순서로 필요한 만큼만 팝니다.
- 재접속 시 쿠키로 본인 상태를 다시 받습니다. 게임 중 연결이 끊겨도 말과 자산을 유지합니다. 90초 후에는 서버 자동 행동이 대신 진행하며, 돌아오면 즉시 직접 조작합니다. 대기실의 미접속 대원은 90초 후 제거하고 방장을 이전합니다.
- 시간 종료 시 연구비 + 소유지 구매가 + 보유 시설 건설비로 자산을 비교하며 동률은 공동 승리입니다.

## 외부 웹사이트 통합

핵심 게임 규칙은 계정 시스템을 모르며, 플레이어의 `id`와 `name`만 필요합니다. 사이트 인증 모듈은 `IdentityAdapter`를 구현합니다.

```ts
import type { IdentityAdapter } from "./identity-adapter";
export function createIdentityAdapter(): IdentityAdapter {
  return {
    async resolve(request) {
      // 사이트의 서명된 세션/인증 토큰을 서버에서 검증합니다.
      const account = await yourSite.verifySession(request.headers);
      if (!account) return null;
      return {
        id: `site:${account.id}`,
        name: account.nickname,
        profile: account.httpsAvatarUrl,
      };
    },
  };
}
```

이 모듈의 경로를 `IDENTITY_ADAPTER_MODULE`에 지정하면 외부 모드로 시작합니다. 화면이 `/api/config`로 모드를 확인하고 사이트 인증 결과로 게임 세션을 자동 발급하므로 닉네임 등록이 필요하지 않습니다. HTTP와 WebSocket 연결·명령 모두 사이트 계정과 게임 세션의 ID를 확인합니다. 어댑터의 요청 입력은 두 경로에서 공통으로 사용할 수 있는 `headers`입니다. 사이트와 게임을 같은 출처 아래 프록시하면 별도 CORS 허용 없이 쿠키와 WebSocket을 함께 사용할 수 있습니다. 호스트 사이트에서 필요에 따라 `/api/session`을 직접 호출할 수도 있습니다. 프로필은 HTTPS 또는 사이트 내 절대 경로만 허용합니다. 브라우저가 전송한 사용자 ID·닉네임·프로필을 인증 근거로 신뢰하면 안 됩니다.

서명형 테스트 어댑터로 자동 접속·프로필·위조 거부·재접속을 검증했습니다. 실제 대상 사이트의 인증 프로토콜과 계정 정보는 제공되지 않았으므로 특정 사이트의 인증 연동은 검증하지 않았습니다. 외부 포인트 API는 사용하지 않습니다.
