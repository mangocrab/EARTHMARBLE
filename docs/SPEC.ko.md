지구마블(Earth Marble) — 온라인 멀티플레이 보드게임 개발 명세서

0. 프로젝트 개요

지구과학을 소재로 한 온라인 멀티플레이 보드게임 '지구마블(Earth Marble)'을 개발한다.

클래식 부루마불의 40칸 정사각형 게임판, 소유지 구매, 건물 건설, 통행료, 주사위 이동, 특수칸 및 카드 시스템을 참고한다.

게임판은 지상현상, 해상현상, 기상현상, 천문현상의 4개 구역으로 구성한다.

본 프로젝트는 독립적인 웹게임으로 먼저 개발한다. 이후 기존 웹사이트에 쉽게 통합할 수 있는 구조로 설계한다.

게임에서 사용하는 연구비는 실제 금전이나 외부 웹사이트 포인트와 연동하지 않는다.

1. 개발 기술 및 아키텍처

1-1. 기술 구성

독립 실행 가능한 웹 애플리케이션으로 제작한다.

권장 기술:

- 프론트엔드: React + TypeScript
- UI: CSS
- 게임판: HTML/CSS 또는 Canvas
- 3D 주사위: Three.js
- 서버: Node.js + TypeScript
- 실시간 통신: Socket.IO

2. 사용자 시스템

개발 단계에서는 독립적인 테스트용 사용자 시스템을 구현한다.

사용자가 닉네임을 설정하여 접속할 수 있도록 한다.

서버에서 사용자별 고유 ID와 안전한 세션을 생성한다.

닉네임만으로 다른 사용자 계정에 접근할 수 없도록 한다.

외부 사이트와 통합하면 해당 사이트의 로그인 정보와 닉네임을 사용한다.

4. 자동 매칭

4-1. 기본 설정

- 최소 인원: 2명
- 최대 인원: 4명
- 실제 사용자만 참가
- AI 참가 불가
- 매칭 검사 주기: 10초

4-2. 매칭 진행

첫 번째 플레이어가 매칭을 시작하면 서버에서 10초 타이머를 시작한다.

10초마다 현재 대기 인원을 확인한다.

- 1명: 다음 10초 대기
- 2명: 2인 게임 시작
- 3명: 3인 게임 시작
- 4명: 4인 게임 시작

4명이 모여도 현재 10초 구간이 끝난 뒤 시작한다.

동시에 여러 사용자가 참가할 때 중복 매칭이나 정원 초과가 발생하지 않도록 한다.

4-3. 매칭 UI

- 현재 매칭 인원
- 다음 검사까지 남은 시간
- 매칭 취소 버튼

매칭이 완료되면 모든 플레이어를 동일한 게임방으로 이동시킨다.

5. 개인 방 생성

5-1. 방 설정

방을 생성할 때 다음 정보를 설정한다.

- 최대 인원: 2/3/4명
- 방 비밀번호
- AI 플레이어 허용 여부
- 게임 제한 시간

5-2. 방 이름

방 이름은 사용자 닉네임을 이용하여 자동 생성한다.

형식:

[닉네임]님의 방

예시:

망고님의 방

내부적으로는 고유한 방 ID와 공유용 방 코드를 사용한다.

5-3. 방 입장

방 코드와 비밀번호를 사용하여 입장한다.

비밀번호는 안전하게 해시하여 서버에서 관리한다.

5-4. 대기실

다음 정보를 표시한다.

- 방 이름
- 방 코드
- 방장
- 참가자 목록
- AI 목록
- 준비 완료 여부
- AI 초대 버튼
- 게임 시작 버튼
- 나가기 버튼

실제 사용자 전원이 준비 완료이고, 사람과 AI를 합쳐 2명 이상이면 방장이 게임을 시작할 수 있다.

6. AI 플레이어

개인 방에서 AI를 초대할 수 있다.

사람과 AI를 합쳐 최대 4명이다.

사람 1명과 AI 1명으로도 게임 시작이 가능하다.

AI 난이도

쉬움

- 단순한 소유지 구매
- 기본 건설
- 제한적인 위험 분석

보통

- 연구비 관리
- 예상 통행료 계산
- 수익성 분석
- 간조 목적지 선택

어려움

- 주사위 확률 분석
- 상대방 자산 분석
- 높은 가치의 소유지 선택
- 건물 투자 전략
- 보관형 카드 활용
- 자산 매각 최적화
- 파산 위험 분석

AI는 사람과 동일한 주사위 확률 및 게임 규칙을 사용한다.

AI는 공개된 정보와 자신의 비공개 정보만으로 행동한다.

AI의 의사결정은 서버에서 실행한다.

7. 인원별 시작 연구비

게임 시작 시 전체 참가 인원에 따라 시작 연구비를 지급한다.

전체 참가 인원에는 AI도 포함한다.

참가 인원| 플레이어당 시작 연구비
2명| 1,500,000
3명| 3,000,000
4명| 3,000,000

적용 방식

게임 시작 시 각 플레이어에게 동일한 금액을 지급한다.

예시:

- 사람 1명 + AI 1명 = 2인 기준, 각각 150만 연구비
- 사람 1명 + AI 2명 = 3인 기준, 각각 300만 연구비
- 사람 2명 + AI 2명 = 4인 기준, 각각 300만 연구비

시작 연구비는 개인별로 독립적으로 관리한다.

게임 도중 플레이어가 파산하더라도 남은 플레이어의 시작 금액을 다시 계산하지 않는다.

게임 시작 후 인원에 따른 금액 변동은 발생하지 않는다.

시작 보상

출발지를 정상적으로 한 바퀴 돌아 통과하면 연구비 20만을 받는다.

완주 횟수도 1 증가한다.

모든 연구비는 정수 단위로 처리한다.

9. 소유지 구매 및 소유권 표시

소유자가 없는 소유지에 도착하면 구매할 수 있다.

구매 가격을 지불하면 소유권을 획득한다.

소유자 색상

- 플레이어 1: 빨강
- 플레이어 2: 파랑
- 플레이어 3: 초록
- 플레이어 4: 노랑

구매한 땅의 오른쪽 위 대각선 모서리를 소유자 색상으로 표시한다.

삼각형의 크기는 칸 전체 면적의 약 10~20%이다.

칸 전체를 소유자 색상으로 칠하지 않는다.

소유권 변경, 매각, 파산 시 실시간으로 갱신한다.

10. 완주 횟수 및 건설 해금

완주 횟수는 플레이어별로 독립적으로 관리한다.

출발지를 정상적으로 한 바퀴 돌아 통과하면 완주 횟수가 증가한다.

완주| 해금
0바퀴| 건설 불가
1바퀴| 관측소
2바퀴| 연구소
3바퀴 이상| 종합연구센터

건물은 자신의 소유지에 도착했을 때만 건설할 수 있다.

건물은 다음 순서로 건설한다.

관측소 → 연구소 → 종합연구센터

한 번의 도착에서는 최대 하나의 시설을 새로 건설한다.

단계 건너뛰기는 불가능하다.

기존에 건설한 건물은 다음 건물을 건설해도 유지된다.

한 소유지에 최대 다음 시설이 함께 존재할 수 있다.

- 관측소 1개
- 연구소 1개
- 종합연구센터 1개

관측소 2개 단계는 존재하지 않는다.

12. 통행료 누적 합산 시스템

일반 소유지의 통행료는 기본 토지 통행료와 현재 건설된 모든 시설의 통행료를 합산하여 계산한다.

통행료를 한 건물의 금액으로 대체하지 않는다.

12-1. 통행료 공식

최종 통행료 = 기본 토지 통행료 + 관측소 통행료 + 연구소 통행료 + 종합연구센터 통행료

단, 실제 건설되어 있는 시설의 통행료만 합산한다.

예시: 지진

기본 통행료: 2,000원

관측소 통행료: 10,000원

연구소 통행료: 90,000원

종합연구센터 통행료: 250,000원

건설 상태| 최종 통행료
건물 없음| 2,000원
관측소| 12,000원
관측소 + 연구소| 102,000원
관측소 + 연구소 + 종합연구센터| 352,000원

통행료를 계산할 때 각 시설의 비용이 중복 합산되지 않도록 한다.

계산 과정:

1. 기본 토지 통행료 확인
2. 관측소 존재 여부 확인
3. 연구소 존재 여부 확인
4. 종합연구센터 존재 여부 확인
5. 존재하는 시설의 통행료 합산
6. 통행료 면제권 사용 여부 확인
7. 최종 금액 결정
8. 방문자 연구비 차감
9. 소유자 연구비 증가

자신의 소유지에서는 통행료가 발생하지 않는다.

소유자가 없는 지역에서도 통행료가 발생하지 않는다.

18. 지구과학 탐사 카드 덱

탐사 카드는 총 30장으로 시작한다.

모든 카드는 게임 시작 시 골고루 무작위로 섞는다.

카드는 하나의 공용 덱으로 관리한다.

플레이어마다 별도의 카드 덱을 만들지 않는다.

18-1. 최초 셔플

게임 시작 시 다음 작업을 진행한다.

1. 탐사 카드 30장을 준비한다.
2. 서버에서 전체 카드를 무작위로 섞는다.
3. 섞인 카드의 순서를 저장한다.
4. 카드 덱을 뒷면으로 표시한다.
5. 게임이 시작될 때까지 카드 순서를 공개하지 않는다.

무작위 셔플은 모든 카드의 순서가 공정하게 섞이도록 구현한다.

18-2. 카드 뽑기

카드 칸에 도착한 플레이어는 공용 덱에서 맨 위 카드 1장을 뽑는다.

뽑은 카드는 덱에서 제거한다.

카드를 다시 무작위로 선택하는 방식이 아니라, 최초에 섞인 덱에서 순서대로 한 장씩 뽑는다.

카드 종류에 따라 처리한다.

즉시 사용 카드

- 카드를 뽑는다.
- 카드 효과를 실행한다.
- 사용된 카드를 버림 카드 더미로 이동한다.

보관형 소모품 카드

- 카드를 뽑는다.
- 플레이어의 보유 카드 목록으로 이동한다.
- 공용 덱에서는 제외한다.
- 사용하기 전까지 다시 뽑히지 않는다.

18-3. 덱 순환

카드 덱의 모든 카드를 뽑으면 남아 있는 카드들을 다시 섞는다.

이때 플레이어가 보유하고 있는 소모품 카드는 제외한다.

예시:

총 카드: 30장

- 일반 카드 25장 사용
- 소모품 카드 5장을 플레이어들이 보유

공용 덱에 남아 있는 카드가 없으면 사용된 일반 카드 25장을 다시 섞어 새로운 덱을 구성한다.

보유 중인 소모품 5장은 덱에 넣지 않는다.

플레이어가 소모품을 사용하면 해당 카드가 공용 덱으로 돌아온다.

18-4. 소모품 카드의 덱 복귀

소모품 카드를 사용하면 카드 효과를 처리한 후 해당 카드를 공용 덱에 반환한다.

반환된 카드는 현재 카드 덱의 무작위 위치에 삽입한다.

덱의 맨 위나 맨 아래에 고정하지 않는다.

예시:

현재 카드 덱에 12장이 남아 있다.

플레이어가 만조 탈출권을 사용한다.

해당 카드를 남은 12장 사이의 무작위 위치에 삽입한다.

이후 다른 플레이어가 해당 카드를 다시 뽑을 수 있다.

소모품 카드를 사용하자마자 항상 다음 플레이어가 뽑도록 해서는 안 된다.

18-5. 덱이 비었을 때

공용 덱이 비면 버림 카드 더미를 섞어 새로운 덱을 만든다.

보관 중인 소모품 카드는 제외한다.

버림 카드 더미도 비어 있고 모든 카드가 플레이어에게 보관된 상태라면 일시적으로 뽑을 수 있는 카드가 없는 상태로 처리한다.

이때 카드 칸에 도착하면 카드 부족 안내를 표시하고 카드 추첨을 생략한다.

소모품 카드가 사용되어 덱으로 돌아오면 다시 추첨할 수 있다.

18-6. 카드 관리 데이터

서버에서는 다음 정보를 관리한다.

- drawPile: 현재 뽑을 카드 덱
- discardPile: 사용된 일반 카드
- heldCards: 플레이어별 보관 카드
- cardId: 카드 고유 ID
- cardType: 카드 효과 종류
- deckVersion: 덱 상태 버전

카드가 동시에 두 위치에 존재하지 않도록 한다.

카드의 총수는 항상 30장을 유지한다.

게임 도중 새로운 카드를 임의로 생성하거나 복제하지 않는다.

파산한 플레이어가 가지고 있던 소모품 카드는 회수하여 덱의 무작위 위치에 삽입한다.

게임 서버는 덱의 실제 순서를 클라이언트에 공개하지 않는다.

카드의 재순환 과정에서 보관 효과가 카드의 복제나 누락을 일으키지 않도록 상태를 분리한다.

20. 소모품 카드 UI

게임 화면에 '보유 카드' 버튼을 제공한다.

플레이어는 자신의 보유 카드를 언제든 확인할 수 있다.

표시 항목

- 카드 이름
- 카드 이미지
- 카드 설명
- 사용 조건
- 효과
- 사용 버튼

사용할 수 없는 상황에서는 버튼을 비활성화한다.

사용 가능한 상황에서는 카드 사용 여부를 선택할 수 있다.

소모품 사용

만조 탈출권:

만조에서 탈출할 때 사용한다.

통행료 면제권:

다른 플레이어에게 통행료를 지불하기 전 사용한다.

간조 이용료 면제권:

간조 이동 시 이용료를 면제한다.

카드 사용은 서버에서 검증한다.

사용한 카드는 플레이어 보관함에서 제거하고 공용 덱의 무작위 위치에 반환한다.

다른 플레이어의 보관형 카드 내용은 공개하지 않는다.

다른 플레이어에게는 보유 카드의 수량만 표시한다.

21. 구매한 소유지 목록 UI

버튼을 누르면 자신이 구매한 모든 땅이 표시된다.

21-1. 목록

보유한 소유지를 카드 형태로 보여준다.

각 카드의 기본 정보:

- 칸 번호
- 소유지 이름
- 구역
- 소유자 색상
- 건설 상태
- 현재 통행료

소유지는 게임판 순서에 따라 정렬한다.

보유한 소유지가 없으면 '아직 보유한 소유지가 없습니다.'라고 표시한다.

21-2. 카드 선택

소유지 카드를 클릭하면 확대된 상세 카드가 나타난다.

상세 카드는 실제 보드게임의 소유지 증서처럼 앞면과 뒷면이 존재한다.

기본적으로 앞면부터 표시한다.

카드를 돌리는 버튼을 누르면 뒷면을 확인할 수 있다.

다시 돌리기 버튼을 누르면 앞면으로 돌아간다.

21-3. 양면 카드 전환

전환은 자연스러운 3D 카드 회전 애니메이션을 사용한다.

- 회전 방향: Y축
- 회전 각도: 180도
- 애니메이션 시간: 약 0.5초
- 앞면과 뒷면이 거꾸로 보이지 않도록 구현

PC에서는 클릭, 모바일에서는 터치로 회전한다.

애니메이션을 줄이는 설정이 켜져 있다면 회전 없이 즉시 전환할 수 있다.

카드 정보는 서버의 실제 게임 상태와 동기화한다.

24. 소유지별 과학 설명

소유지 카드 앞면에 사용할 기본 과학 설명을 작성한다.

각 설명은 수정 가능한 게임 데이터로 관리한다.

지상현상

1. 지진

지각에 쌓인 응력이 갑자기 해소되면서 지반이 흔들리는 현상이다. 주로 단층의 급격한 움직임으로 발생하며, 에너지는 지진파의 형태로 전달된다.

3. 단층

지각에 작용하는 힘으로 암석이 깨지고, 그 경계 양쪽의 암석이 상대적으로 이동한 구조이다. 단층의 움직임은 지진 발생과 밀접한 관련이 있다.

4. 화산 활동

지하의 마그마가 지표로 상승하면서 용암, 화산재, 가스 등을 방출하는 현상이다. 판의 경계나 열점에서 활발하게 나타나며 새로운 지형을 형성하기도 한다.

5. 제주 화산섬

제주도는 오랜 화산 활동으로 형성된 섬이다. 현무암과 다양한 화산 지형이 분포하며, 용암동굴과 오름 등 화산 활동의 흔적을 관찰할 수 있다.

6. 습곡산맥

지각에 강한 압축력이 작용해 지층이 휘어지면서 형성되는 산맥이다. 주로 판이 충돌하는 지역에서 나타나며 히말라야산맥 등이 대표적이다.

8. 풍화 작용

암석이 온도 변화, 물, 공기, 생물 등의 영향으로 부서지거나 화학적으로 변하는 과정이다. 풍화는 암석이 이동하지 않은 상태에서도 일어날 수 있다.

9. 침식 작용

하천, 바람, 빙하, 파도 등이 지표의 암석이나 퇴적물을 깎아 내는 과정이다. 침식된 물질은 이동하여 다른 장소에 퇴적되기도 한다.

해상현상

11. 해류

해수가 일정한 방향으로 지속적으로 이동하는 흐름이다. 바람, 수온과 염분에 따른 밀도 차이, 지구 자전 등이 해류의 형성에 영향을 준다.

13. 파랑

바람 등의 영향으로 수면에 발생한 물결이다. 파랑은 주로 에너지를 전달하며, 해안에 도달하면 침식과 퇴적 작용을 일으킬 수 있다.

14. 용승

바다 깊은 곳의 차가운 해수가 표층으로 올라오는 현상이다. 영양염류가 풍부한 심층수가 상승하면서 해양 생물의 생산성을 높이기도 한다.

15. 해저터널

해저터널은 바다 아래의 지층을 통과하도록 만든 인공 구조물이다. 건설 과정에서는 해저 지형, 암석의 특성, 지하수 압력 등을 조사해야 한다.

16. 난류

주변보다 상대적으로 따뜻한 해수가 이동하는 해류이다. 난류는 이동 경로 주변의 기온과 해양 생태계에 영향을 준다.

18. 수온약층

바다에서 깊이가 증가함에 따라 수온이 급격하게 낮아지는 층이다. 수온약층은 해수의 수직 혼합을 제한하여 열과 물질의 이동에 영향을 준다.

19. 엘니뇨

열대 태평양 중부와 동부의 해수면 온도가 평년보다 높아지는 현상이다. 무역풍과 대기 순환의 변화에 관련되며 세계 여러 지역의 강수와 기온에 영향을 준다.

기상현상

21. 구름

대기 중의 수증기가 응결하거나 얼어 작은 물방울 또는 얼음 입자가 모인 것이다. 공기의 상승과 냉각이 구름 형성의 주요 원인이다.

23. 장마

우리나라 여름철에 지속적인 강수가 나타나는 현상이다. 주로 정체전선과 수증기 공급, 대기 흐름 등이 영향을 주며 지역과 해마다 강수 특성이 다를 수 있다.

24. 안개

지표 부근의 공기 중에 작은 물방울 등이 떠 있어 수평 시정이 낮아지는 현상이다. 지표 부근 공기의 냉각이나 수증기 공급 등에 의해 형성된다.

25. 태풍의 눈

태풍 중심 부근에 위치한 비교적 바람이 약하고 구름이 적은 영역이다. 눈을 둘러싼 눈벽에서는 매우 강한 바람과 비가 나타날 수 있다.

26. 번개

구름 내부 또는 구름과 지표 사이 등에 전하 차이가 커지면서 발생하는 전기 방전 현상이다. 급격하게 가열된 공기가 팽창하면서 천둥이 발생한다.

27. 폭설

짧은 시간 또는 일정 기간 동안 많은 눈이 내리는 현상이다. 충분한 수증기와 적절한 기온, 상승 기류 등이 폭설 형성에 영향을 준다.

28. 제트기류

대류권 상부 부근에서 좁고 강하게 나타나는 바람의 흐름이다. 중위도 지역의 기온 차이와 대기 순환에 관련되며 항공기 운항에도 영향을 준다.

29. 계절풍

계절에 따라 주된 바람의 방향이 바뀌는 현상이다. 대륙과 해양의 가열 차이 등에 따른 기압 배치 변화가 주요 원인이다.

천문현상

31. 달의 위상

달이 지구 주위를 공전하면서 지구에서 보이는 달의 밝은 부분이 달라지는 현상이다. 태양, 지구, 달의 상대적인 위치에 따라 초승달, 상현달, 보름달 등이 나타난다.

32. 갯벌

밀물과 썰물의 영향으로 해안의 넓은 퇴적 지형이 드러나거나 잠기는 곳이다. 조석은 달과 태양의 기조력 등에 영향을 받으며 갯벌은 다양한 생물의 서식지가 된다.

33. 행성

항성 주위를 공전하는 천체의 한 종류이다. 태양계에는 수성부터 해왕성까지 8개의 행성이 있으며, 크기와 구성 물질 등에 따라 특징이 다르다.

34. 유성

우주 공간의 작은 물체가 지구 대기권에 빠른 속도로 진입하면서 밝은 빛을 내는 현상이다. 공기와의 상호작용으로 물체와 주변 기체가 가열되면서 빛이 발생한다.

36. 월식

태양, 지구, 달이 거의 일직선으로 놓여 달이 지구의 그림자에 들어가는 현상이다. 보름달 무렵에 발생할 수 있으며 달의 일부 또는 전체가 어두워진다.

37. 일식

태양, 달, 지구가 거의 일직선으로 놓여 달이 태양을 가리는 현상이다. 관측자의 위치에 따라 부분일식, 개기일식, 금환일식 등이 나타난다.

39. 빅뱅

빅뱅 이론은 약 138억 년 전 우주가 매우 뜨겁고 밀도가 높은 상태에서 팽창해 왔다는 현대 우주론의 설명이다. 빅뱅은 우주 공간의 특정 지점에서 일어난 일반적인 폭발을 뜻하지 않는다.

26. 개인 자산 UI

게임 화면에는 항상 자신의 연구비를 표시한다.

자신의 정보 패널에서 다음 내용을 확인할 수 있도록 한다.

- 현재 연구비
- 소유한 땅
- 소유지별 건설 상태
- 보유 카드
- 완주 횟수
- 건설 해금 단계
- 총자산

빠른 접근 버튼

- 내 소유지
- 보유 카드
- 자산 상세보기

연구비 변동 시 실시간으로 갱신한다.

다른 플레이어의 소유지와 현재 연구비는 공개하지만, 보유 소모품 카드의 상세 정보는 소유자에게만 표시한다.

---

27. 만조

10번 만조는 이동 제한 칸이다.

- 최대 3번의 자기 차례 동안 탈출 시도
- 더블이면 즉시 탈출
- 만조 탈출권 사용 가능
- 탈출 실패 시 남은 횟수 감소
- 3번 실패하면 제한 해제
- 다음 차례부터 정상 이동

연속 더블 3회로 이동한 경우에도 같은 규칙을 적용한다.

---

28. 간조

30번 간조는 자유 이동 칸이다.

간조에 도착하면 다음 자기 차례에 목적지를 선택할 수 있다.

목적지는 30번을 제외한 모든 칸 중에서 선택한다.

이동 시 갯벌 소유자에게 이용료 20만을 지불한다.

갯벌 소유자가 없거나 자신이 소유자인 경우 무료이다.

이동 후 목적지의 효과를 처리한다.

자신의 일반 소유지에 도착하면 해금 조건에 따라 건설할 수 있다.

---

29. 자연보호기금

20번 환급소

누적된 기금 전액을 지급한다.

지급 후 기금은 0으로 초기화한다.

38번 납부처

도착하면 15만 연구비를 납부한다.

탐사 카드에서 발생하는 환경 관련 기금도 동일한 기금으로 적립한다.

모든 참가자가 현재 적립금을 확인할 수 있다.

---

30. 자산 매각 및 파산

연구비가 부족하면 자산을 매각할 수 있다.

매각 가능한 항목:

- 관측소
- 연구소
- 종합연구센터
- 일반 소유지
- 특수 소유지

각 자산은 기본적으로 구매 또는 건설 비용의 50% 가격으로 은행에 매각한다.

건물이 있는 땅은 건물을 먼저 매각한 후 토지를 매각할 수 있다.

건물을 매각하면 그 건물의 통행료는 합산 대상에서 제외한다.

필수 비용을 지불할 수 없으면 파산한다.

파산한 플레이어는 게임에서 제외된다.

해당 플레이어의 소유지는 은행으로 반환된다.

보유한 소모품 카드도 공용 덱의 무작위 위치에 반환한다.

---

31. 승리 조건

마지막까지 파산하지 않은 플레이어가 승리한다.

게임 제한 시간이 종료되면 최종 자산을 계산한다.

최종 자산:

- 보유 연구비
- 소유지 가치
- 건물 가치

가장 높은 순자산을 가진 플레이어가 승리한다.

기본 게임 제한 시간은 30분이며 개인 방에서는 변경할 수 있다.

AI도 같은 승리 조건을 적용한다.
