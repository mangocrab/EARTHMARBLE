## 운영 범위

Node 24 내장 SQLite를 사용하는 단일 프로세스 서버입니다. 서버에서 유효한 명령만 처리하고 상태를 매번 저장합니다. 방 비밀번호와 세션 토큰 원본은 저장하지 않습니다. 소켓별 연결이 아닌 사용자별 요청 제한을 사용합니다. 복수 탭은 동일한 플레이어 세션을 공유합니다.

현재 단일 게임 참가자는 한 방에만 속할 수 있습니다. 종료된 게임은 로비로 나간 뒤 새 방을 만듭니다. 매칭 대기열 자체는 서버 재시작 시 초기화되며 진행 중인 방·게임과 세션은 복구됩니다. 운영 시 HTTPS·DB 백업·접근 제어는 배포 환경에서 설정해야 합니다.

## 새로고침 복구와 화면별 사용성
