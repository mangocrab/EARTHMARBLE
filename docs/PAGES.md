# GitHub Pages — 혼자 AI와 플레이

이 빌드는 사람 한 명과 AI 1~3명이 플레이하는 정적 웹게임입니다. 게임 규칙, 주사위, AI와 저장 처리를 브라우저에서 실행하며 게임 API나 Socket.IO 서버가 필요하지 않습니다. 기존 온라인 멀티플레이 빌드는 별도로 유지합니다.

## 플레이

배포 워크플로가 성공하면 다음 주소에서 플레이합니다.

https://mangocrab.github.io/EARTHMARBLE/

1. 닉네임을 등록합니다.
2. **AI와 탐사 시작**에서 AI 수·각 난이도·제한 시간을 선택합니다.
3. 주사위를 굴리고 구매·건설·카드 사용 등을 진행합니다.

연구비는 게임 전용입니다. 새로고침하면 이 기기의 같은 브라우저에서 이어집니다. 탭을 숨기거나 닫아 둔 시간은 게임 제한 시간에 포함하지 않습니다. 상단 **일시정지/계속하기**로 직접 멈출 수도 있습니다. **새 탐사**는 확인 화면을 거쳐 현재 게임을 종료하고 새 설정으로 돌아갑니다.

저장은 브라우저의 `localStorage`(`earthmarble.solo.v1`)를 사용합니다. 사이트 데이터를 삭제하거나 다른 기기·브라우저·시크릿 세션으로 옮기면 기존 게임을 이어갈 수 없습니다. 저장이 차단된 경우 안내를 표시하고 현재 페이지의 플레이는 계속할 수 있습니다.

## 모바일 전체 게임판

기본 화면에서 40칸 전체가 가로·세로 화면 안에 들어갑니다. 지도 크기는 사용 가능한 폭과 높이 중 작은 값에 맞춰 자동 조절합니다. 화면이 좁으면 칸 이름을 짧게 표시하고, 칸을 누르거나 **지역 상세 보기**를 선택하면 전체 이름·과학 설명·경제 정보를 읽을 수 있습니다.

**크게 보기**는 선택 사항이며, **전체 지도**로 돌아올 수 있습니다. 행동 버튼·연구비·남은 시간은 판을 가리지 않는 별도 영역에 표시합니다. 소유지·보유 카드·자산·탐사 일지는 하단 버튼으로 확인합니다.

## 행동과 카드 표시

- 보드 중앙에는 현재 행동과 최근 기록, 플레이어 자산 아래에는 각자의 마지막 행동을 표시합니다. 연구비 변화는 자산 근처의 `+금액` / `-금액`으로 표시합니다.
- 주사위 연출 후 말을 한 칸씩 이동합니다. 6칸 이상은 이동 거리에 따라 속도를 높여 6칸과 같은 1.44초 안에 이동합니다. 카드에 의한 추가 이동과 더블 추가 굴림은 별도 이유를 표시합니다. 연출 중에는 행동 시간 예산을 소비하지 않습니다.
- 간조에서는 맵의 원하는 칸을 누르면 이동합니다. 간조 자신은 목적지로 선택할 수 없으며, 이용료 정산 후 이동합니다. 만조 강제 이동을 제외하면 출발지에 도착하거나 통과할 때 연구비 20만을 받습니다.
- 구매 또는 건설이 가능하면 도착한 땅 카드가 자동으로 열립니다. 양옆 선택 버튼은 모바일 세로 화면에서는 카드 아래의 좌우 두 영역에 배치합니다.
- 건물 버튼은 관측소 → 연구소 → 종합연구센터 순서로 사용합니다. 완주 횟수·연구비가 허용하면 한 도착에서 연속으로 건설하고 **건설 마침**으로 끝냅니다. 이번 요청은 원래 명세의 도착당 한 건물 제한을 대체합니다.
- 땅 카드 앞면에도 구매·시설 가격을 표시하며, 카드 돌리기는 내용 스크롤과 분리해 하단에 고정합니다.
- 탐사 덱의 실제 화면 위치에서 맨 위 카드를 밀어 꺼내 중앙으로 가져와 뒤집습니다. 뽑은 카드는 보관형도 모두에게 먼저 공개합니다. 공개 연출이 끝난 뒤 뽑은 사람에게만 효과를 적용하며, 보관형은 그 사람의 보유 카드로 이동합니다. 현재 손패와 남은 덱 순서는 공개하지 않습니다.
- 카드 칸은 노란색, 모서리를 제외한 특수 칸은 주황색, 빅뱅은 검정색 띠로 표시합니다.

만조 탈출 더블도 추가 굴림을 얻습니다. 더블로 도착한 카드 칸의 효과 및 전 지구 탐사의 재추첨을 모두 처리한 뒤 같은 대원이 계속하며, 만조 발생·세 번째 연속 더블·파산 시에는 추가 굴림이 취소됩니다. 전 지구 탐사는 한 바퀴 보상 후 돌아온 카드 칸에서 다시 뽑습니다.

연구소 구조조정은 토지와 현재 건물의 은행 매각 대금 합계로 가장 비싼 땅을 고릅니다. 수동 건물 매각은 해당 땅의 비싼 건물부터 가능합니다. 정산 중 **부족분 자동 매각**은 모든 소유지의 건물을 비싼 순서로 먼저 팔고, 부족하면 토지를 싼 순서로 팔며, 정산할 금액이 모이면 멈춥니다. AI와 시간 초과 자동 처리도 같은 순서를 사용합니다.

정산은 별도 창에서 처리합니다. 지불·면제권·자동 매각·직접 매각·파산 버튼은 하단에 고정하고 통행료 계산 내역만 스크롤합니다. 창을 닫았다면 행동 영역의 **정산 화면 열기**로 다시 엽니다. 매각한 땅의 소유 삼각형은 한 번 밝아진 뒤 약 1.4초 동안 사라지고, 매각한 건물도 서서히 사라집니다. 실제 소유권·시설료는 매각 시 즉시 갱신합니다.

뽑기 시작 시 카드의 가로·세로는 덱 카드와 같습니다. 카드 비율을 유지하면서 중앙의 읽기 크기로 확대합니다. 세 번째 더블의 만조 이동은 저장된 보상 플래그와 무관하게 출발지 보상을 금지합니다.

추가 회귀 검증: 주사위 36개 조합의 정확한 경로·중복 틱 방지, 공개 전 효과 미적용, 공개 후 한 번만 지급, 순차 다중 건설과 순서 위반 거절, 이동 중 저장 복구를 확인합니다. 정적 모바일 브라우저에서도 맵 이동·연속 건설·금액 표시·고정 회전 버튼·공개 후 보관을 검증합니다.

## 로컬 개발 및 정적 빌드

Node.js 24 이상에서:

```sh
npm ci
npm run dev:solo
```

Pages 배포용 빌드 및 검증:

```sh
npm test
npm run build:pages
npm run test:pages
npm run preview:pages
```

- `dist-pages/`만 정적 호스팅에 배포합니다.
- `build:pages`는 Vite `pages` 모드이며, 빌드 시 AI 단독 모드를 선택합니다.
- 기본 프로젝트 경로는 `/EARTHMARBLE/`입니다. GitHub Actions에서는 실제 Pages 경로를 설정합니다.
- 다른 저장소에서는 `GITHUB_REPOSITORY=소유자/저장소`로 기본 경로를 결정합니다. 사용자 홈페이지 저장소(`*.github.io`)는 `/`를 사용합니다. `PAGES_BASE_PATH`로 경로를 명시할 수도 있습니다.
- Node 서버·SQLite·비밀 키는 정적 게임 실행에 필요하지 않습니다.

## GitHub 배포

`.github/workflows/pages.yml`이 `main` 푸시 또는 수동 실행으로 테스트 → 정적 빌드 → Pages 브라우저 검증 → 아티팩트 업로드 → 배포를 수행합니다.

GitHub 저장소의 **Settings → Pages → Source**는 **GitHub Actions**여야 합니다. 배포 파일은 `dist-pages`에 한정하므로 서버 DB와 로컬 저장 파일을 업로드하지 않습니다. GitHub Actions의 배포 성공과 실제 URL 응답을 확인한 뒤 게시 완료로 판단합니다.
