# GitHub Pages — AI 및 온라인 플레이

이 빌드는 AI 싱글플레이와 실제 사용자 간 온라인 플레이를 지원하는 정적 웹게임입니다. 게임 규칙, 주사위, AI와 저장 처리를 브라우저에서 실행하며 별도 게임 API나 Socket.IO 서버가 필요하지 않습니다. 기존 Node 서버 빌드도 유지합니다.

## 플레이

배포 워크플로가 성공하면 다음 주소에서 플레이합니다.

https://mangocrab.github.io/EARTHMARBLE/

1. 닉네임을 등록합니다.
2. **방 만들기**에서 최대 인원(2/3/4명), 비밀번호, AI 초대 허용 여부, 제한 시간을 정합니다. 방 유형을 따로 선택하지 않습니다.
3. 방에서 난이도를 골라 **AI 초대**를 누릅니다. **준비 완료 → 탐사 시작**으로 시작합니다. AI만 초대한 방은 싱글플레이입니다.
4. 주사위를 굴리고 구매·건설·카드 사용 등을 진행합니다.

연구비는 게임 전용입니다. 새로고침하면 이 기기의 같은 브라우저에서 이어집니다. 탭을 숨기거나 닫아 둔 시간은 게임 제한 시간에 포함하지 않습니다. 상단 **일시정지/계속하기**로 직접 멈출 수도 있습니다. **새 탐사**는 확인 화면을 거쳐 현재 게임을 종료하고 새 설정으로 돌아갑니다.

저장은 브라우저의 `localStorage`(`earthmarble.solo.v1`)를 사용합니다. 사이트 데이터를 삭제하거나 다른 기기·브라우저·시크릿 세션으로 옮기면 기존 게임을 이어갈 수 없습니다. 저장이 차단된 경우 안내를 표시하고 현재 페이지의 플레이는 계속할 수 있습니다.

## 온라인 매칭과 방 참가

- **자동 매칭**에서 빠른게임(2인) 또는 일반게임(4인)을 선택합니다. 선택한 인원이 모이면 바로 시작하며 AI로 빈자리를 채우지 않습니다. 일반게임에서 1~2명이 30초 이상 기다리면 빠른게임 전환을 제안합니다. 거절하면 일반 대기열을 유지합니다.
- **방 만들기**로 만든 방은 `[닉네임]님의 방` 이름으로 열린 방 목록에 나타납니다. 모두 준비하면 방장이 시작합니다.
- **방 참가하기**에서 열린 방을 선택합니다. 공개 방은 바로 참가하고, 잠긴 방만 비밀번호를 입력합니다. 코드 입력은 하지 않습니다. 방장은 게임이 끝날 때까지 창을 열어 두어야 합니다.
- 목록은 방장·현재 인원/정원·비밀번호 유무·AI 허용·시간을 표시하며 자동 갱신합니다. 대기 중 정원이 찬 방은 참가 버튼이 비활성화됩니다. 진행 중인 방은 어둡게 표시하고 게임 중·참가자 이름·경과 분을 보여줍니다. 종료하거나 닫힌 방은 사라집니다.
- AI 허용 여부에 따라 대기실의 AI 초대 버튼을 표시합니다. 방 생성 직후 친구 연결을 준비하며, 준비 중이거나 연결이 실패해도 AI 초대·시작은 가능합니다. 같은 방에 AI만 초대해 시작하면 로컬 싱글플레이로 전환하며 자동 저장합니다.

Pages 방 목록은 대기실/목록 브라우저 중 하나가 임시 WebRTC 중계 역할을 맡습니다. 방장은 자신의 실제 게임 연결로 공개 방 정보와 진행 여부·참가자 이름·시작 시각만 등록하며 비밀번호·손패·게임 상태는 목록에 포함하지 않습니다. 중계 브라우저가 닫히면 남은 브라우저가 중계를 다시 맡고 열린 방을 재등록합니다. Node 서버 빌드는 인증된 소켓으로 목록을 조회·갱신합니다.

별도 게임 서버 주소 없이 PeerJS 공개 신호 서버(`0.peerjs.com`)와 Google·Cloudflare의 공개 STUN 서비스를 사용합니다. 게임 상태·행동은 암호화된 WebRTC 데이터 채널로 주고받으며, 방장 브라우저가 규칙·주사위·AI를 처리합니다. 방장 연결이 끊기면 같은 게임을 계속할 수 없으므로 방장 창을 유지하세요. 직접 WebRTC 연결을 막는 네트워크나 일부 NAT 조합에서는 접속할 수 없습니다. 운영용 TURN 중계는 포함하지 않으며, 테스트에서는 로컬 TURN을 사용합니다. 싱글플레이 자동 저장은 AI만 참가한 싱글플레이에 적용합니다.

기존 Node 서버를 별도로 운영한다면 `설정 → 전용 게임 서버 주소 (선택)`을 지정하여 그 서버의 매칭·방 기능을 이용할 수도 있습니다. 서버 주소를 지정하지 않으면 WebRTC를 사용합니다.

설정의 효과음 음량은 0~100%로 저장되며 0%는 음소거입니다. 주사위·이동·카드·구매·건설·자금 변화·차례·종료에 효과음을 재생합니다. Web Audio로 합성하며 외부 음원 다운로드는 필요하지 않습니다.

### 온라인 연결 테스트

`npm run test:peer`는 실제 두 Chromium 브라우저를 로컬 PeerJS 신호 서버와 TCP TURN 중계로 연결합니다. GitHub Actions에서는 Ubuntu 24.04에 사전 설치된 Chrome과 `coturn/coturn:4.6.3` 컨테이너를 사용하여 실행 중 Ubuntu 패키지를 내려받지 않습니다. `coturn`의 `turnserver`가 필요하며 `TURN_SERVER_BIN`으로 실행 파일을 지정할 수 있습니다. `VITE_SIGNAL_URL` / `VITE_TURN_URL`은 테스트용 신호·중계 경로를 주입하며, 배포 빌드는 공개 신호 서버와 STUN을 사용합니다. 브라우저의 UDP 보호 정책은 변경하지 않습니다.

## 관전·채팅·전적

진행 중인 방의 **관전하기**로 입장합니다. 비밀번호 방은 같은 비밀번호가 필요합니다. 플레이어 목록을 누르면 그 대원의 연구비·최근 행동·내 소유지·보유 카드 화면으로 전환됩니다. 관전자는 게임 행동을 할 수 없습니다. 개인 방의 방장은 게임 중에도 상단 **관전 목록**에서 관전자를 강퇴할 수 있으며 같은 방 재입장은 차단됩니다. 매칭 방에는 강퇴 권한을 가진 방장이 없습니다. 관전 정원은 50명입니다.

개인 방은 자유 채팅·퀵채팅·이모티콘을, 매칭 방은 참가자와 관전자 모두 정해진 문구와 카탈로그 이모티콘 퀵채팅을 사용합니다. 양이·지온은 각 10종이며 캐릭터 버튼으로 선택합니다. 전송한 이모티콘은 채팅 내역과 화면 하단 최근 채팅에 표시되며 새로고침 후에도 남습니다. 참가자는 3초, 관전자는 5초에 한 번 전송하며 호스트/서버에서도 검사합니다. 관전 메시지는 보라색 **관전** 배지를 표시합니다. 메시지는 최근 80개를 유지합니다.

대기실의 상대 이름이나 게임 중 플레이어를 누르면 임시 프로필과 전적을 봅니다. 내 전적은 상단 이름 또는 설정에서 확인합니다. 전체 판수·승패·승률과 가장 많이 플레이한 인원전을 보여주며 **상세보기**에서 2·3·4인전과 전체를 비교합니다. 2·3인전은 1등, 4인전은 1·2등이 승리입니다. 동점은 공동 순위이며 파산자는 패배입니다. AI만 상대하는 싱글플레이와 관전은 전적에서 제외합니다.

Pages 전적은 해당 기기의 브라우저 저장소에 보관하는 임시 기록입니다. 상대 전적도 상대 기기가 제공한 값이며 공식 계정 기록으로 검증하지 않습니다. 기기 변경·저장소 삭제 시 이어지지 않습니다. Node 서버 빌드는 SQLite에 게임별 한 번만 기록하며 재시작 후에도 유지합니다. 실제 사이트 계정·프로필·서버 이모티콘 연결 방법은 [웹사이트 연동 안내](WEBSITE.md)를 참고하세요.

## 모바일 전체 게임판

기본 화면에서 40칸 전체가 가로·세로 화면 안에 들어갑니다. 지도 크기는 사용 가능한 폭과 높이 중 작은 값에 맞춰 자동 조절합니다. 화면이 좁으면 칸 이름을 짧게 표시하고, 칸을 누르거나 **지역 상세 보기**를 선택하면 전체 이름·과학 설명·경제 정보를 읽을 수 있습니다.

**크게 보기**는 선택 사항이며, **전체 지도**로 돌아올 수 있습니다. 행동 버튼·연구비·남은 시간은 판을 가리지 않는 별도 영역에 표시합니다. 소유지·보유 카드·자산·탐사 일지는 하단 버튼으로 확인합니다.

## 행동과 카드 표시

- 보드 중앙에는 현재 행동과 최근 기록, 플레이어 자산 아래에는 각자의 마지막 행동을 표시합니다. 연구비 변화는 자산 근처의 `+금액` / `-금액`으로 표시합니다.
- 주사위 연출 후 말을 한 칸씩 이동합니다. 6칸 이상은 이동 거리에 따라 속도를 높여 6칸과 같은 1.44초 안에 이동합니다. 카드에 의한 추가 이동과 더블 추가 굴림은 별도 이유를 표시합니다. 연출 중에는 행동 시간 예산을 소비하지 않습니다.
- 간조에서는 맵의 원하는 칸을 누르면 이동합니다. 간조 자신은 목적지로 선택할 수 없으며, 이용료 정산 후 이동합니다. 만조 강제 이동을 제외하면 출발지에 도착하거나 통과할 때 연구비 20만을 받습니다.
- 구매 또는 건설이 가능하면 도착한 땅 카드가 자동으로 열립니다. 양옆 선택 버튼은 모바일 세로 화면에서는 카드 아래의 좌우 두 영역에 배치합니다.
- 건물 버튼은 관측소 → 연구소 → 종합연구센터 순서로 사용합니다. 완주 횟수·연구비가 허용하면 한 도착에서 연속으로 건설하고 **건설 마침**으로 끝냅니다. 이번 요청은 원래 명세의 도착당 한 건물 제한을 대체합니다.
- 땅 카드 앞면에도 구매·시설 가격을 표시하며, 카드 돌리기는 내용 스크롤과 분리해 하단에 고정합니다.
- 탐사 덱의 실제 화면 위치에서 맨 위 카드를 밀어 꺼내 중앙으로 가져와 뒤집습니다. 뽑은 카드는 보관형도 모두에게 먼저 공개합니다. 공개 연출이 끝난 뒤 뽑은 사람에게만 효과를 적용하며, 보관형은 그 사람의 보유 카드로 이동합니다. 일반 참가자에게 다른 사람의 현재 손패와 남은 덱 순서는 공개하지 않습니다. 관전자는 선택한 대원의 현재 손패를 볼 수 있으며 덱 순서는 볼 수 없습니다.
- 카드 칸은 노란색, 모서리를 제외한 특수 칸은 주황색, 빅뱅은 검정색 띠로 표시합니다.

만조 탈출 더블도 추가 굴림을 얻습니다. 더블로 도착한 카드 칸의 효과 및 전 지구 탐사의 재추첨을 모두 처리한 뒤 같은 대원이 계속하며, 만조 발생·세 번째 연속 더블·파산 시에는 추가 굴림이 취소됩니다. 전 지구 탐사는 한 바퀴 보상 후 돌아온 카드 칸에서 다시 뽑습니다.

연구소 구조조정은 토지와 현재 건물의 은행 매각 대금 합계로 가장 비싼 땅을 고릅니다. 수동 건물 매각은 해당 땅의 비싼 건물부터 가능합니다. 정산 중 **부족분 자동 매각**은 모든 소유지의 건물을 싼 순서로 먼저 팔고, 부족하면 토지를 싼 순서로 팔며, 정산할 금액이 모이면 멈춥니다. AI와 시간 초과 자동 처리도 같은 순서를 사용합니다.

파산 선언도 자동 매각부터 처리합니다. 납부 가능하면 정산 후 생존하며, 그래도 부족하면 모든 자산 매각금과 현금 전부를 채권자(또는 자연보호기금)에 지급하고 파산합니다. 사용·파산한 보관 카드는 버림 더미로 이동하며, 뽑을 덱이 소진된 뒤에만 다시 섞입니다.

환급소 칸의 카드 양면에는 현재 자연보호기금 적립액을 표시합니다. 효과음은 부드러운 목재 타격음과 둥근 사인파 음색을 사용하며, 주사위 구르는 소리와 칸별 이동 소리는 다른 효과음과 독립적으로 재생합니다. 설정에서 두 소리를 따로 미리 들을 수 있습니다.

정산은 별도 창에서 처리합니다. 지불·면제권·자동 매각·직접 매각·파산 버튼은 하단에 고정하고 통행료 계산 내역만 스크롤합니다. 창을 닫았다면 행동 영역의 **정산 화면 열기**로 다시 엽니다. 매각한 칸에는 ‘매각’ 표시와 테두리 강조가 나타나며, 소유 삼각형은 한 번 밝아진 뒤 약 4초에 걸쳐 사라집니다. 건물도 서서히 사라집니다. 상세 카드·정산창이 지도를 가리는 동안에는 연출을 멈췄다가 창을 닫으면 보여줍니다. 실제 소유권·시설료는 매각 시 즉시 갱신합니다.

뽑기 시작 시 카드의 가로·세로는 덱 카드와 같습니다. 카드 비율을 유지하면서 중앙의 읽기 크기로 확대합니다. 세 번째 더블의 만조 이동은 저장된 보상 플래그와 무관하게 출발지 보상을 금지합니다.

게임 종료 시 열려 있던 땅 카드·보유 카드·설정 창을 닫고 최종 결과 창을 표시합니다. **로비로 돌아가기** 버튼은 결과 창 하단에 고정하며, 대원이 4명인 작은 모바일 화면에서도 결과 내역과 분리해 항상 누를 수 있습니다.

추가 회귀 검증: 주사위 36개 조합의 정확한 경로·중복 틱 방지, 공개 전 효과 미적용, 공개 후 한 번만 지급, 순차 다중 건설과 순서 위반 거절, 이동 중 저장 복구를 확인합니다. 정적 모바일 브라우저에서도 맵 이동·연속 건설·금액 표시·고정 회전 버튼·공개 후 보관을 검증합니다.

## 로컬 개발 및 정적 빌드

Node.js 24 이상에서:

```sh
npm ci
npm run dev:solo
```

Pages 배포용 빌드 및 검증:

```sh
npm test
npm run build:pages
npm run test:pages
npm run preview:pages
```

- `dist-pages/`만 정적 호스팅에 배포합니다.
- `build:pages`는 Vite `pages` 모드이며, 브라우저 실행 모드를 선택합니다.
- 기본 프로젝트 경로는 `/EARTHMARBLE/`입니다. GitHub Actions에서는 실제 Pages 경로를 설정합니다.
- 다른 저장소에서는 `GITHUB_REPOSITORY=소유자/저장소`로 기본 경로를 결정합니다. 사용자 홈페이지 저장소(`*.github.io`)는 `/`를 사용합니다. `PAGES_BASE_PATH`로 경로를 명시할 수도 있습니다.
- Node 서버·SQLite·비밀 키는 정적 게임 실행에 필요하지 않습니다.

## GitHub 배포

`.github/workflows/pages.yml`이 `main` 푸시 또는 수동 실행으로 테스트 → 정적 빌드 → Pages 브라우저 검증 → 아티팩트 업로드 → 배포를 수행합니다.

GitHub 저장소의 **Settings → Pages → Source**는 **GitHub Actions**여야 합니다. 배포 파일은 `dist-pages`에 한정하므로 서버 DB와 로컬 저장 파일을 업로드하지 않습니다. GitHub Actions의 배포 성공과 실제 URL 응답을 확인한 뒤 게시 완료로 판단합니다.

## 다크모드·채팅 미리보기·방 복구

설정에서 다크모드를 선택하면 판·카드·채팅·정산에 적용하고 기기에 저장합니다. 상단 **채팅**과 **관전자 N**은 글자로 표시하며, 화면 아래 최근 메시지 두 개는 채팅 창을 열지 않아도 읽습니다. 작은 휴대폰에서는 **일시정지·새 탐사**를 설정에서 사용합니다. PC 판은 사용 가능한 세로 높이에 맞추고 플레이어·개인 기록 영역은 각각 스크롤합니다.

업데이트한 버전에서 새로 만든 Pages 방은 같은 탭에서 새로고침할 때 복구합니다. 재접속 자격을 지원하지 않는 이전 버전의 방과 섞이지 않도록 공개 목록과 매칭 신호를 버전별로 분리합니다. 방장은 규칙·덱·게임 상태를, 참가자/관전자는 재접속 자격을 탭의 sessionStorage에 보관합니다. 참가자는 다른 사람의 재접속 자격이나 전체 덱을 받지 않습니다. 방장이 새로고침하면 상대는 최대 45초 자동 재연결을 시도합니다. 대기실의 끊긴 자리는 90초 동안 유지합니다. **나가기·강퇴·매칭 취소**는 복구 정보를 지웁니다. 탭을 닫거나 저장소 사용이 차단된 환경까지 복구를 보장하지 않으며, 방장 브라우저가 계속 닫혀 있으면 서버 없는 게임은 계속할 수 없습니다.

개인 방은 결과 화면의 **방으로 돌아가기**로 같은 대원·방 설정·채팅을 유지하고 준비를 다시 합니다. 매칭 게임만 **로비로 돌아가기**를 사용합니다. 재경기는 별도 게임 식별자로 기록하여 전적을 누락하거나 두 번 더하지 않습니다. 효과음은 주사위와 같은 짧고 낮은 목재 공명으로 통일하고 긴 전자 멜로디를 제거했습니다.

### 다크모드의 표면과 카드

[이랜서의 다크모드 UI 디자인 글](https://www.elancer.co.kr/blog/detail/293)의 명암·색상 대비·깊이감 원칙을 참고했습니다. 기본 UI는 녹색 대신 무채색으로 구성하며 배경보다 패널, 패널보다 모달·공개 카드가 밝은 회색이 되도록 구분합니다. 공개 카드 앞면과 덱 뒷면 모두 어두운 표면을 사용합니다. 뽑기 카드의 배경 밝기와 본문 대비를 실제 브라우저에서 검증하며, 구역 띠·플레이어 말·관전 배지의 색은 구분 기능을 유지합니다.

게임마다 무작위로 진행 순서를 뽑으며 참가자 목록과 말 번호에 표시합니다. 빠른게임(2인)은 60초 동안 혼자 대기하면 어려움 AI와 시작하고, 일반게임(4인)은 계속 사람을 기다립니다. 행동 타이머와 공용 덱·버림 장수는 지도 위의 별도 줄에 항상 표시합니다. 하단의 **채팅 열기**에서 대화할 수 있으며 읽지 않은 메시지는 숫자 배지로 표시합니다.

Docker가 있는 Linux 환경에서는 컨테이너 중계를 직접 사용할 수도 있습니다.

```bash
bash tests/fixtures/turn-container.sh start
EARTH_TEST_TURN_EXTERNAL=true npm run test:peer
bash tests/fixtures/turn-container.sh stop
```

중계는 루프백 주소에만 바인딩하며 테스트 전용 계정을 사용합니다. `EARTH_TEST_TURN_EXTERNAL`은 테스트 프로세스에서만 읽습니다.

개인 방은 최근 채팅 아래 입력칸에서 바로 대화할 수 있습니다. 전송 대기 중에도 다음 메시지를 작성할 수 있고, 채팅·퀵채팅·이모티콘 창을 바꿔도 초안이 유지됩니다. 퀵채팅과 이모티콘은 하단의 별도 버튼으로 열며, 매칭에서도 이모티콘만 전송할 수 있습니다. 채팅 중 내 차례가 오면 입력 포커스를 가져가지 않는 알림을 표시합니다.
