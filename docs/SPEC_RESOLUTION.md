## 추가 검증

- 카드 30장 각각의 정확한 지급/납부 금액, 기금 적립, 목적지, 보관, 완주, 가장 비싼 소유지 및 시설의 50% 매각을 확인합니다.
- 후속 요청에 따라 사용·파산한 보관 카드는 버림 더미로 이동합니다. 남은 덱 순서 보존, 덱 소진 후 재셔플 및 30장 보존을 확인합니다.
- 3인 매칭, 4인 조기 시작 방지, 8명의 두 그룹 배정과 중복 참가 방지를 실제 10초 검사 구간으로 확인합니다.
- 90초 유예 전후의 대기실 퇴장·방장 이전, 게임 자동 행동 인계와 재접속 후 직접 제어 복귀를 검증합니다.
- 보관 카드·덱 순서·미완료 통행료를 SQLite에 저장한 뒤 재시작해 복구하고 통행료가 한 번만 지급되는지 확인합니다.
- 두 브라우저에서 증서를 열어 둔 상태로 건설·시설 매각·토지 매각·파산에 따른 소유자와 통행료 갱신을 확인합니다.

90초 경계 테스트는 **테스트 프로세스에만 주입한 제어 시계와 주사위**를 사용해 시간을 정확히 전진시킵니다. 프로덕션 앱에는 시계나 주사위 결과를 조작하는 API가 없습니다. SQLite 복구 및 열린 증서 동기화 테스트 일부는 유효한 중간 게임 상태를 픽스처로 저장하고 실제 서버·소켓·브라우저를 실행합니다. 별도의 기본 브라우저 테스트는 닉네임 등록부터 방 생성·게임 시작·주사위 이동까지 실제 흐름으로 실행합니다.

## 실제 운영에서 남는 검증 범위

- 실제 연동 대상 웹사이트의 인증 계약·키·접속 정보가 제공되지 않아 해당 사이트에 연결한 검증은 하지 않았습니다. 서명형 테스트 어댑터로 인터페이스와 게임 동선만 검증했습니다.
- 모바일 검증은 터치·가로/세로 화면을 설정한 Chromium입니다. 실물 기기, Safari·Firefox의 실행 결과는 없습니다.
- AI 확률 모델은 미래 카드와 사용자 선택을 알지 못하는 공개 정보 기반 예측입니다. 현재 부채의 매각 조합을 그 예측의 손실 함수에 대해 최적화하며, 모든 미래 상황을 고려한 전체 게임의 최적 전략이라는 뜻은 아닙니다.
- 서버는 기존과 같이 단일 프로세스 + SQLite 운영을 전제로 합니다. 다중 서버·부하·실제 배포는 별도 범위입니다.
